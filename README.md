## Responsible use of data
- All test messages and conversations are **simulated**. No real staff, student or organisational data is used.
- Names, phone numbers and reference numbers that appear in tests are **fictitious placeholders**.
- **No API keys, credentials or secrets** are stored in this repository. Keys are held in Google Colab Secrets.
